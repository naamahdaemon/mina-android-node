# Security policy

This is an experimental native Mina port and Android application. It has not received an independent security audit. Use current builds, keep encrypted key backups and begin testing on devnet.

## Reporting a vulnerability

Use **Security → Report a vulnerability** in this GitHub repository when private vulnerability reporting is available. If that option is unavailable, arrange a private contact with the maintainer through their GitHub profile before sending sensitive details. Do not publish an exploit or secret in a public issue while seeking a private channel.

Never send a private key, wallet password, recovery phrase, signing keystore or GitHub token. Provide the affected version/source commit, Android version and reproduction steps using a disposable test key. Review and redact diagnostic logs before attaching them.

Security fixes target the current main branch and newly generated APKs. Older experimental APKs do not have a separate maintenance guarantee. A canonical block or successful synchronization is not a security certification.
